## hw_tensor_compilers/include/graph/

Данная папка представляет собой реализацию `namespace graph_engine` - представление нейронной сети в виде вычислительного графа

* `graph.h`: 
      Вычислительный граф нейронной сети реализуется через `class Graph;`
* `node.h`: 
      Граф состоит из различных операций типов `enum class OperatorType;`
      Операции в графе представляются вершинами `class Node;`
* `attributes.hpp`:
      Хранит атрибуты `Attributes Node::attr`, специфичные для отдельных операций графа.
* `value.h`: 
      Операции графа создают типизированные тензора. 
      Для хранения размеров и типов данных используется дескриптор `class Value;`
* `datatype.h`:
      Указывает тип данных, хранимых в тензоре через `enum class DataType;`
* `shape.h`:
      Указывает ранг и форму тензора через `class Shape;`
* `tensor.hpp`:
      Тензор, создаваемых из конкретных данных. Хранит данные и свою типизацию.
      Реализуется через `class Tensor;`
