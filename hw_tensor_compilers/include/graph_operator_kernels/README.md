## hw_tensor_compilers/include/graph_operator_kernels/

Данная папка представляет собой реализацию конкретных проходов для конкретных операций вычислительного графа.

`hw_tensor_compilers/include/passes/graph_pass.h` заключает контракт на то, как должен выглядеть проход по графу.

Далее проход создает контракт на то, как выглядит обработчик абстрактной операции его прохода. 
Таковым например является `hw_tensor_compilers/include/passes/semantics_inferer_pass/semantics_inferer_pass.h`.

В данной папке лежат реализации таких контрактов. Они разделены на подпапки по различным проходам графа.
