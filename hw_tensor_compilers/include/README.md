## hw_tensor_compilers/include
* graph 
       Внутреннее представление графа `graph_engine::Graph`. 
       Содержит классы, составляющие вычислительный граф нейронной сети - такие как например `Shape`, `OperatorType`.
* passes 
       Определения проходов над графом и пайплайна этих проходов.
* graph_operator_kernels
       Реализации конкретных ядер обработки вершин графа.
       Содержит код, специфичный для конкретного прохода и конкретного оператора графа.
* io 
       Содержит классы, реализующие ввод/вывод в системе.
