## hw_tensor_compilers/
* `data`    - файлы моделей/нейросетей, используемые для пробных запусков/тестирования.
* `deps`    - подкключаемые внешние библиотеки, конфигурации, CMakeLists.txt
* `include` - заголовочные файлы проекта
* `src`     - файлы исходного кода проекта
* `tests`   - тесты проекта
